# Deep Learning

Utilisation de plusieurs méthodes pour la prédiction des données MNIST avec uniquement 100 labels.

## Description
Ce projet est un projet de Deep Learning, pour la deuxième année de master Machine Learning 
pour la Science des Données à l’université Paris Cité pour l’année académique 2023-2024. Il est 
basé sur la prédiction des données MNIST avec uniquement 100 labels. L’objectif est de bien 
comprendre l’architecture de différents réseaux de neurones et l’utilisation de plusieurs méthodes 
afin de les comparer. 
Ce document contient la description des méthodes utilisées, la baseline : réseaux sur uniquement 
100 exemples, les résultats obtenus, les références, le code en annexes.
